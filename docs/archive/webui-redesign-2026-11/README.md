# WebUI Redesign Exploration Archive (November 2026)

During the November 2026 WebUI aesthetic overhaul, three distinct interactive HTML design prototypes were generated to address card-in-card nesting across Tsukaima's Settings, Plugins, and Chat surfaces.

- **Selected Direction:** **Option A — Paper & Ink Editorial** (promoted to [../../design/webui-editorial-redesign.md](../../design/webui-editorial-redesign.md) and [../../design/prototypes/option-a-editorial.html](../../design/prototypes/option-a-editorial.html)).
- **Archived Alternatives (kept here for reference & selective pattern borrowing):**
  - [option-b-precision.html](option-b-precision.html) — **Precision Studio** (Linear / Raycast dark-first console craft). Notable reusable patterns: dense OpenAI model capability matrix table, category-tabbed Policy key-value table with dirty-row left indicators and floating save bar.
  - [option-c-atelier.html](option-c-atelier.html) — **Calm Atelier Sheets** (macOS Sequoia / Arc floating sheet + borderless tonal groups). Notable reusable patterns: collapsible Policy disclosure rows with inline summary pills (`Settle 1.2s · 6/min`), two-pane Prompts & Personas editor.
